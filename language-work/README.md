# مسار شغل اللغة — سيرة ذاتية وقوالب تقديم

## الملفات

| الملف | الاستعمال |
|-------|-----------|
| `cv.pdf` | السيرة الجاهزة للإرسال |
| `cv.html` | المصدر — عدّله بأي محرر نصوص |
| `render.js` | `node render.js cv.html` → يطلع PDF + PNG جديد |

## لازم تعبّيه قبل الإرسال

- `your@email.com` → إيميلك
- `+972-00-000-0000` → رقمك
- `[Your institution]` / `[Years]` / `[Degree / Program]` / `[School]` / `[City]` / `[Year]`
- إذا ما عندك خبرة تصميم مدفوعة — احذف القسم أو بدّله بشغل فعلي عملته

**لا تكتب خبرة ما عملتها.** أغلب المنصات بتختبرك عملياً، والكذب بينكشف بالامتحان الأول.

```

אני מתרגם פרילנס מתל אביב-יפו, עובד בין ערבית (שפת אם),

אני זמין 20-30 שעות בשבוע, כולל עבודות דחופות באותו יום
לטקסטים קצרים.

קורות החיים מצורפים. אשמח לבצע תרגום מבחן קצר.

בברכה,
מוחמד עותמאן
[טלפון] | [אימייל]
```

## تحذير من النصب

- **لا تدفع ولا شيكل** مقابل "تدريب" أو "تسجيل" أو "ضمان شغل". المنصات الحقيقية بتدفعلك، مش العكس.
- لا تعطي صور بطاقة الهوية إلا لمنصة معروفة وبعد ما تتأكد من الرابط الرسمي.
- إذا طلبوا منك تستقبل فلوس وتحولها لحد تاني — هاد غسيل أموال. ارفض فوراً.

## ملاحظة ضريبية

القوانين والأرقام بتتغير.
