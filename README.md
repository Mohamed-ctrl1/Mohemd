# منصة التحضير لامتحان العبرية — הבניינים והפועל

موقع تدريب كامل بواجهة عربية (RTL) للتحضير لامتحانات اللغة العبرية، مركّز على:
**הבניינים** السبعة، **הפועל**، **פעיל וסביל**، جذور الأفعال، التصريف، وتحليل الفعل داخل الجملة.

كل البيانات تُحفظ محليًا في المتصفح (LocalStorage) — بلا خادم، بلا تسجيل دخول، وبلا أي مفتاح API.

---

## 1. التشغيل

```bash
npm install          # تثبيت المكتبات
npm run dev          # تشغيل التطوير على http://localhost:3000
```

للنسخة النهائية:

```bash
npm run build        # بناء الموقع كملفات ثابتة في مجلد out/
npm start            # خدمة المجلد على http://localhost:3000
```

> البناء يحمّل الخطوط (Cairo + Frank Ruhl Libre) مرة واحدة ويستضيفها ذاتيًا،
> فالموقع بعد البناء لا يحتاج أي اتصال بشبكة خارجية.
>
> الموقع **ثابت بالكامل** (`output: "export"`): لا خادم ولا قاعدة بيانات،
> فيمكن رفع مجلد `out/` على أي استضافة ملفات.

## 2. الآيفون والآيباد

### النشر على GitHub Pages

الريبو فيه `.github/workflows/deploy.yml` ينشر تلقائيًا عند كل push.
يحتاج خطوتين لمرة واحدة من صاحب الريبو:

1. **اجعل الريبو عامًا**: Settings ← General ← أسفل الصفحة Danger Zone ←
   *Change repository visibility* ← Public.
   (Pages المجاني لا يعمل على ريبو خاص.)
2. **فعّل Pages**: Settings ← Pages ← *Source* اختر **GitHub Actions**.

بعدها بدقيقتين يصير الموقع على:
`https://mohamed-ctrl1.github.io/Mohemd/`

### تثبيته كتطبيق على الشاشة الرئيسية

1. افتح الرابط في **سفاري** (وليس كروم — إضافة التطبيقات تعمل من سفاري فقط).
2. زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية** ← إضافة.
3. تظهر أيقونة باسم «עברית — الامتحان»، وتفتح بملء الشاشة بلا شريط سفاري.

بعد أول فتحة يعمل الموقع **بلا إنترنت** (Service Worker يحفظ كل الصفحات
والدروس والأسئلة). التقدّم والعلامات محفوظة داخل التطبيق على الجهاز نفسه.

### معاينة نسخة GitHub Pages محليًا

```bash
npm run build:pages     # بناء بمسار /Mohemd مثل الاستضافة تمامًا
npm run preview:pages   # http://localhost:4300/Mohemd/
```

### بديل بلا نشر: شبكة البيت

شغّل على الكمبيوتر `npm run dev -- -H 0.0.0.0`، ثم افتح من الآيفون
`http://<عنوان-الكمبيوتر>:3000` وأنتما على نفس الواي فاي.

> ملاحظة: البيانات محفوظة لكل جهاز على حدة. لنقل تقدّمك من الكمبيوتر إلى
> الآيفون استخدم **تصدير نسخة احتياطية** ثم **استيراد ملف** في صفحة الإعدادات.

## 4. ما داخل الموقع

### الصفحات

| المسار | الصفحة |
|---|---|
| `/` | لوحة التحكم: آخر علامة، المتوسط، نسبة الصحيح، عدد الأسئلة المحلولة، نقاط القوة والضعف، تقدّم كل موضوع، آخر الامتحانات |
| `/learn` | قائمة الدروس وحالة إكمالها |
| `/learn/[slug]` | الدرس: شرح مقسّم إلى أجزاء قصيرة + أمثلة + تمارين فورية مع تلميح قبل الحل |
| `/bank` | بنك الأسئلة كاملًا مع فلترة بالموضوع والبنيان والصعوبة والنوع |
| `/exam/setup` | إعداد الامتحان |
| `/exam/run` | حل الامتحان |
| `/exam/results/[id]` | النتيجة والتحليل التفصيلي |
| `/weakness` | نقاط الضعف مرتّبة + خطة مراجعة مقترحة |
| `/mistakes` | دفتر الأخطاء ونظام المراجعة المتباعدة |
| `/history` | سجل الامتحانات السابقة |
| `/settings` | الإعدادات الافتراضية + تصدير/استيراد نسخة احتياطية + حذف البيانات |

### الدروس

1. **نظرة عامة على הבניינים** — الخريطة الكاملة للأوزان السبعة وعلاماتها.
2. **درس لكل بنيان** (7 دروس): פעל، נפעל، פיעל، פועל، הפעיל، הופעל، התפעל —
   الاسم وقراءته بالعربية، الماضي والحاضر والمستقبل والأمر، علامات التعرّف،
   أمثلة عبرية مترجمة، الفرق عن الأوزان المتشابهة، علاقته بالمعلوم والمجهول،
   أخطاء شائعة، وتمارين بعد الشرح.
3. **פעיל וסביל** — الفاعل ومن وقع عليه الفعل، التحويل بين الصوتين، أزواج
   פיעל/פועל و הפעיל/הופעל، ولماذا נפעל و התפעל ليسا مجهولًا دائمًا.
4. **الجذور والتصريف** — استخراج الجذر، تحديد البنيان والزمن والشخص والعدد والجنس.
5. **مهارات الامتحان** — خطوات تحليل الفعل في الجملة واختيار الصيغة المناسبة.

### بنك الأسئلة

**933 سؤالًا** مقسّمة على 8 مواضيع و14 نوعًا و4 مستويات صعوبة:

| الصعوبة | العدد |
|---|---|
| سهل | 224 |
| متوسط | 309 |
| صعب | 286 |
| صعب جدًا | 114 |

الأنواع الأربعة عشر: اختيار من متعدد، صح/خطأ، كتابة البنيان، كتابة الجذر،
كتابة الزمن، פעיל/סביל، إكمال جملة، تحويل معلوم↔مجهول، تصحيح خطأ، مطابقة،
تحليل فعل في سياق، التمييز بين بنيانين، كتابة حرة، وسؤال مركّب متعدد المهارات.

## 5. كيف تُبنى الأسئلة (ولماذا هي موثوقة)

البنك يُجمَّع من مصدرين، وكلاهما مفصول تمامًا عن واجهة المستخدم:

1. **`src/data/questions.manual.ts`** — أسئلة مكتوبة ومدققة يدويًا، وفيها
   الأسئلة السياقية والجمل الطويلة والأسئلة المركّبة.
2. **`src/data/generator.ts`** — مولّد **حتمي** (deterministic) يبني أسئلة من
   قاعدة الأفعال المدققة في `src/data/verbs.ts` (88 فعلًا، كل صيغة مكتوبة يدويًا
   ومراجعة). لا يوجد توليد عشوائي للمحتوى: العشوائية محصورة في ترتيب الخيارات،
   وهي مثبّتة بمفتاح نصّي فيبقى الترتيب نفسه في كل تشغيل.

**حماية من الأسئلة الملتبسة:** قبل توليد أي سؤال تعرّف، يفحص المولّد إن كانت
الصيغة نفسها تحتمل أكثر من بنيان أو أكثر من جذر أو أكثر من زمن داخل القاعدة —
وإن احتملت، تُستثنى من سؤال التعرّف أو يُضاف لها سياق يحدد المقصود. مثال:
«נכתב» ماضٍ وحاضر معًا بلا حركات، فلا يُسأل عن زمنها إلا داخل جملة فيها
«עכשיו» أو «אתמול».

كل سؤال يحمل: المعرّف، النص، الموضوع، الصعوبة، النوع، الخيارات، الإجابة
الصحيحة، شرح سبب صحة الإجابة، تلميحًا، والقاعدة والدرس المرتبطين به.

`npm run validate` يرفض البناء إذا وُجد سؤال بلا إجابة صحيحة، أو بمعرّف مكرر،
أو بخيارات مكررة، أو مرتبط بدرس غير موجود.

## 6. نظام الامتحانات والتصحيح

جاهزة: سريع (10)، تدريبي (20)، شامل (40)، نقاط الضعف (15)، مراجعة الأخطاء (15).
ومخصص بالكامل: الموضوعات، العدد (5–60)، الصعوبة، المؤقت، إظهار التلميحات،
والتصحيح بعد كل سؤال أو بعد التسليم.

أثناء الحل: رقم السؤال والتقدم والمؤقت، تنقّل حر وتغيير الإجابات، حفظ تلقائي
بعد كل إجابة (تُستعاد كما هي بعد إعادة تحميل الصفحة)، وتأكيد قبل التسليم.
في وضع الامتحان لا تُكشف الإجابة الصحيحة قبل التسليم إطلاقًا.

**نظام العلامات:** العلامة = مجموع النقاط المكتسبة ÷ مجموع النقاط الممكنة × 100.
السؤال ذو الإجابة الواحدة: نقطة كاملة أو صفر، ولا نقاط جزئية للخطأ.
السؤال متعدد الحقول (تحليل / مركّب): كل حقل نقطة مستقلة، ولا يُحسب السؤال
صحيحًا بالكامل إلا إذا صحّت كل الحقول — فالإجابة الناقصة لا تُعدّ صحيحة.
أسئلة الكتابة تُقارَن بعد تطبيع النص (حذف الحركات والمسافات وصور الجذر
المختلفة: `כ.ת.ב` و`כתב` و`כ-ת-ב` كلها مقبولة).

صفحة النتائج تعرض: العلامة من 100، عدد الصحيح والخطأ، نسبة النجاح، الوقت
المستغرق، العلامة لكل موضوع، وفي كل سؤال: إجابتك والإجابة الصحيحة وشرح
السبب والقاعدة التي أخطأت في تطبيقها ورابط الدرس — مع زر لإعادة حل الأسئلة
الخاطئة وزر لامتحان جديد من المواضيع الضعيفة.

## 7. تحليل نقاط الضعف

لكل موضوع يُحسب: عدد الأسئلة المحلولة، نسبة الصحيح، آخر أداء، الأداء عبر
الامتحانات، و**درجة ثقة** في التقييم مبنية على عدد الإجابات المتاحة.

لا يُصنَّف الطالب ضعيفًا في موضوع من خطأ واحد: التصنيف يحتاج حدًّا أدنى من
الإجابات، والصفحة تفرّق صراحةً بين «نقص بيانات» و«ضعف أداء حقيقي».

تُقترح خطة مراجعة من خمس خطوات (مراجعة القاعدة ← 5 أسئلة سهلة ← 5 متوسطة ←
أسئلة صعبة ← اختبار قصير)، وكل خطوة رابط جاهز، وتتحدّث الخطة بعد كل امتحان.

## 8. دفتر الأخطاء والمراجعة المتباعدة

كل خطأ يُحفظ تلقائيًا مع السؤال وإجابتك والإجابة الصحيحة وشرح القاعدة وتاريخ
الخطأ وعدد مرات الخطأ. السؤال الذي أخطأت فيه مستحقّ للمراجعة فورًا، وكل إجابة
صحيحة ترفعه صندوقًا فتطول فترة عودته: **1 ← 3 ← 7 ← 16 ← 35 يومًا**، ويُعدّ
متمكَّنًا بعد ثلاث إجابات صحيحة فيُستثنى من المراجعة.

## 9. حفظ التقدم والنسخ الاحتياطي

يُحفظ في LocalStorage: الدروس المكتملة، الامتحانات، العلامات، كل الأسئلة
المحلولة، الأخطاء، نقاط القوة والضعف، إعدادات الامتحان، والامتحان الجاري غير
المسلّم. البنية تحمل رقم إصدار (`DATA_VERSION`) ويُدقّق كل حقل عند التحميل،
فالبيانات التالفة أو القديمة تُرقّى بلا انهيار.

**البيانات محلية لهذا المتصفح ولا تنتقل تلقائيًا بين الأجهزة**، وتُفقد إذا حذفت
بيانات الموقع. استخدم «تصدير نسخة احتياطية» في صفحة الإعدادات قبل تنظيف
المتصفح أو الانتقال لجهاز آخر، ثم «استيراد ملف» على الجهاز الآخر.

## 11. عرض العربية والعبرية

الواجهة كلها `dir="rtl"` و`lang="ar"`. كل مقطع عبري يُعرض داخل عنصر بصنف `.he`
أو `.he-block` مع `unicode-bidi: isolate` وخط عبري مستقل، فلا يختلط ترتيب
الحروف العبرية مع النص العربي المحيط — وهذا مُختبَر آليًا في `npm run test:e2e`.
