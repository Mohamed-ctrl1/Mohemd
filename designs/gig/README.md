# غلاف الخدمة (Gig Cover) – 1280×769

للاستعمال على Fiverr / خمسات / مستقل كصورة رئيسية للخدمة.

## التعديل والتصدير

```
node render.js fiverr-cover.html
```

الصور `a.png` `b.png` `c.png` `d.png` هي النماذج الظاهرة بالغلاف.
بدّلها بتصاميمك الجديدة (نفس الأسماء) والغلاف بيتحدث لحاله.

## المقاسات المطلوبة بالمنصات

| المنصة | مقاس الغلاف |
|--------|-------------|
| Fiverr | 1280×769 px |
| خمسات | 600×400 px (صغّر نفس الصورة) |
| مستقل | 800×600 px |

## ملاحظة

النماذج بالغلاف فيها أسماء محلات حقيقية كـ placeholder.
قبل النشر: بدّل الأسماء لأسماء عامة (مثلاً "MEAT HOUSE", "CAFE ROMA")
عشان ما تدّعي إنك اشتغلت مع محل ما اشتغلت معه.
