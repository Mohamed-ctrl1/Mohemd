# תבניות עיצוב – MEATBAL גבעת שמואל / قوالب تصميم

مقاس 1080×1350 px (إنستغرام بوست).

## كيف تعدّل وتصدّر PNG

1. افتح ملف `.html` بأي محرر نصوص وبدّل النص (التلفون، العنوان، السعر).
2. شغّل: `node render.js sukkot-tray.html student-discount.html`
3. بتطلع ملفات PNG بنفس الأسماء.

أو: افتح الـ HTML بالمتصفح وخذ Screenshot.

## الملفات

| الملف | الاستعمال |
|-------|-----------|
| `sukkot-tray.html/.png` | عرض مجش شيفودים لسوكوت |
| `student-discount.html/.png` | خصم طلاب بار إيلان |
| `base.css` | الإطار المشترك (مقاس 1080×1350) |
| `heebo.css` + `fonts/` | خط Heebo العبري (SIL OFL) |

## لازم تبدّله قبل النشر

- `03-000-0000` → التلفون الحقيقي
- `רח׳ הרצל 00` → العنوان الحقيقي
- السعر والمكونات → حسب ما يعطيك صاحب المحل
- إذا المحل كشير: ضيف سطر الشهادة الصحيحة — لا تكتبها من راسك
