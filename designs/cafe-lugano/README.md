# תבנית עיצוב – Cafe Lugano / قالب تصميم

مقاس 1080×1350 px. ستايل فاتح (كافيه) — عكس ستايل مطعم اللحمة الغامق.

## التعديل والتصدير

```
node render.js breakfast-for-two.html
```

بيطلع PNG بنفس الاسم. أو افتح الـHTML بالمتصفح وخذ سكرين شوت.

## لازم تبدّله قبل النشر

- `03-000-0000` → التلفون الحقيقي
- `₪89` → السعر الحقيقي (اسأل صاحب المحل)
- `07:00–12:00` و `א׳–ה׳` → ساعات وأيام العرض الحقيقية
- مكونات الفطور → حسب المنيو الحقيقي
- `פתוח כל יום מ-07:00` → ساعات الفتح الحقيقية
