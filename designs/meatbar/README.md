# תבנית עיצוב – עסקית צהריים / قالب عسكيت تسهوريים

مقاس 1080×1350 px. ستايل غامق فخم — لمطاعم اللحمة والستيك هاوس.

## التعديل والتصدير

```
node render.js business-lunch.html
```

## لازم تبدّله قبل النشر

- `MEATBAR` → اسم المحل الحقيقي (مكانين: فوق وتحت)
- `@meatbar` → الهاندل الحقيقي
- `03-000-0000` → التلفون
- `רח׳ 00, תל אביב` → العنوان
- الأطباق والأسعار → من المنيو الحقيقي
- `12:00–17:00` → ساعات العسكيت الحقيقية

## ملاحظة مهمة

هاد القالب لعروض **الأكل** فقط. لا تستعمله لعروض مشروبات كحولية
(هابي أور، بيرة، كوكتيل) — خارج نطاق الشغل الحلال.
إذا طلب منك صاحب المحل إعلان كحول، اعتذر واعرض عليه بديل من الأكل.
