# أوراق تمارين — دروس خصوصية C#

## التصدير

```
node pdf.js csharp-worksheet-01.html
```

بيطلع PDF مقاس A4 جاهز للإرسال أو الطباعة.

## الاستعمال

الورقة الأولى **مجانية** — بتبعتها بمجموعة الكورس كطُعم.
اللي بيحل وبيعلق = طالب مهتم. اللي بيسأل "كيف طلع الجواب؟" = زبون.

## لصنع ورقة جديدة

انسخ الملف وبدّل:
- الكود بالـ `<code>` (استعمل `&lt;` بدل `<` داخل الكود)
- أعمدة جدول التتبّع حسب المتغيرات بالكود
- الحلول بالصفحة الثانية

**قاعدة:** كل ورقة لازم يكون فيها **فخ واحد** مقصود
(`>` مقابل `>=`، أو `i++` مقابل `++i`، أو خروج من الحلقة).
الفخ هو سبب احتياج الطالب لشرح — وهو سبب دفعه.
